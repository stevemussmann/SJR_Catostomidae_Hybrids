# SJR_Catostomidae_Hybrids

This repository contains scripts and data associated with:

Mussmann, Steven M., Melody J. Saltzgiver, Tracy A. Diver, Eliza I. Gilbert, Michael A. Farrington, and Benjamin J. Schleicher 2026. Semipermeable species boundaries permit gene flow but prevent a hybrid swarm among sympatric catostomids of a desert ecosystem. Heredity \<in revision>

Some data files too large for Github were deposited in an [OSF](https://osf.io/) repository at: [https://doi.org/10.17605/OSF.IO/ER27M](https://doi.org/10.17605/OSF.IO/ER27M)
